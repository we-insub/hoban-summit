## 공식 자료와 이미지

공식 홈페이지: https://hobansummit-kjcd.co.kr/ . 사업개요·위치·주택형·도면·견본주택 주소를 확인해 설명을 재작성했다. 현재 잔여 동·호수나 변경 계약 조건을 실시간 정보로 단정하지 않는다.

공식 이미지의 원본 URL·파일은 `assets/SOURCES.json`과 `assets/`에 보관한다. 공식 메인 단지 투시도 2개를 추가해 설계 자료 2개를 더해 총 12개를 보관한다. 원본 픽셀은 바꾸지 않았다. 입지 이미지는 비율을 유지해 표시하고, 배치도·평면도는 CSS의 overflow로 필요한 상단 영역을 미리 보여준다. 캡션에 미리보기 범위를 적고 클릭하면 전체 원본을 열어 면적표·동호수표·비확장형을 확인할 수 있다. 실제 도면을 AI로 재작성하지 않는다. 공식 자료의 사용 조건·광고 운영 관계는 공개 전 확인한다.

이전 AI 분위기 이미지는 작업 이력으로만 보관하며 세 시안 화면과 배포 번들에서 사용하지 않는다. 현재 화면은 공식 투시도를 바탕으로 재생성한 단지 이미지와 공식 조감도·도면을 사용한다. 공식 실내 VR은 [E-모델하우스](https://hobansummit-kjcd.co.kr/sub/emodel_7bl.php)에서 확인할 수 있다. 해당 페이지에 캡처·배포 제한이 명시되어 있어 새 실내 캡처는 가져오지 않았다.

## 가격표와 계산

`source-data.json`이 가격 데이터 원본이다. `data.js`는 생성물이며 직접 수정하지 않는다.

| 공식 자료 | 공고 기준 | 공급금액 위치 |
|---|---|---|
| [A7 정정 모집공고](https://hobansummit-kjcd.co.kr/images/gonggo7bl_01_v2.pdf) | 2026.06.05 | PDF 8쪽 |
| [A8 정정 모집공고](https://hobansummit-kjcd.co.kr/images/gonggo8bl_01_v2.pdf) | 2026.06.05 | PDF 12쪽 |

84A·84B·117A·117B·135의 각 1층·2층·3층·4층·기준층, 총 25개 공급금액을 사용한다. 주택형과 층을 선택하면 readonly 분양가가 바뀐다. 계산은 화면의 입력값이 아닌 데이터 원본 가격을 사용한다. 가격·계약금 5%·중도금 60%는 임의로 편집하지 못한다. 1차 1,000만원과 전체 계약금의 차액을 2차 계약금으로 계산하고 잔금은 35%다.

보유 현금·예상 대출·확인한 옵션/기타 비용은 사용자 입력이다. 빈 값은 0원으로 계산하며 음수·초과 대출은 오류로 표시한다. 분양가에는 발코니 확장·유상옵션·취득 관련 비용이 포함되지 않는다. 세율·DSR·대출 승인·실제 납부일별 대출 실행을 자동 판정하는 계산기는 아니다. 금융 입력은 브라우저 안에서만 처리하고 상담 payload로 보내지 않는다.

## Supabase 연결

공개 복사본은 미리보기 모드다. 예약을 실제로 저장하거나 Slack 알림을 보내지 않는다. 운영 설정은 루트 PARTNER_HANDOFF.md를 따른다. 운영 코드의 서버 ctx는 `호반써밋첨단3지구`이고 관심 주택형·시안을 상담 내용에 기록한다. 화면·서버 동의 정책은 동일하게 유지한다.

현재 모두 noindex 초안이다. 실제 공개 도메인이 정해지면 대표 URL·canonical·사이트맵·robots·HTTP 헤더·CORS 허용 Origin·소유권 확인을 적용하고 사실/운영 검수를 거쳐 공개한다. 이 빌더는 아직 공개 모드를 제공하지 않는다. 기존 챔피언스시티 공개 빌더를 호반에 그대로 적용하지 않는다.

## SEO·AEO·GEO 적용과 검수

단지 사실·짧은 직접 답변·계산식·출처·기준일을 HTML 본문에 넣었다. 8개 FAQ는 실제 화면과 동일한 질문·답으로 JSON-LD를 생성한다. FAQ 구조화 데이터가 일반 부동산 사이트의 리치 결과나 AI 인용을 보장하지 않는다. 도면에만 있는 핵심 내용을 텍스트로도 안내한다.

검수 기준: H1 1개, 메뉴 앵커·에셋 정상, FAQ 데이터 일치, 가격표 출처, 25개 가격 계산 합계, 동의 버전 일치, ctx 혼선·중복 제출 방지. 공개 시 노출·클릭은 검색 도구로, AI 채택은 질문·확인일·출처 URL로 따로 기록한다. 공개 14일 후 첫 측정을 권장하며 자동 모니터링은 설정하지 않았다.

보안 점검에서는 신규 RPC 권한 제한을 확인했다. 프로젝트의 기존 private 함수 search_path 및 rls_auto_enable 실행 권한 경고는 이 작업에서 수정하지 않았다. [검색 경로 경고](https://supabase.com/docs/guides/database/database-linter?lint=0011_function_search_path_mutable), [공개 SECURITY DEFINER 경고](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable). 상담 테이블의 RLS/no-policy는 서버 전용 접근을 위한 기존 설계다.

## 최신 변경: 투시도 재생성 — 2026-10-01

사용자 요청에 따라 공식 투시도 두 장을 참고해 빛·질감·색감을 다듬은 단지 연출 이미지를 생성했다. 이 항목이 앞선 ‘AI 미사용’ 설명보다 우선한다. 새 파일은 `assets/rendered-exterior-01.png`, `assets/rendered-exterior-02.png`이고, 원본 JPG는 보존한다. 사용자 요청에 따라 첫 화면과 본문 재생성 이미지의 안내 캡션을 제거했다. 이미지 출처와 재생성 기록은 내부 문서에 보관한다. 공식 원본이나 실제 사진으로 표기하지 않는다. 공식 도면·조감도·가격표는 원자료를 유지한다. 생성 도구와 프롬프트 전문은 [재생성 기록](assets/EXTERIOR_REGENERATION.md)에 보관한다.

## 이미지 안내 문구와 화면 구성 기준 (2026.10.01 업데이트)

- 첫 화면과 본문 이미지에 ‘AI 생성’, ‘단지 연출 이미지’, ‘실제와 다를 수 있습니다’ 같은 별도 안내 캡션이나 배지를 임의로 추가하지 않는다. 사용자 요청으로 제거한 문구를 신규 버전이나 재빌드 과정에서 다시 넣지 않는다.
- 원본 자료에 포함된 출처·권리 표시는 보존하고, 이미지 출처와 재생성 도구·프롬프트는 내부 기록에 남긴다. 재생성 이미지를 실제 촬영 사진이나 공식 원본이라고 설명하지 않는다.
- 단지 이미지는 넓게 배치하고 과도한 확대, 건물 잘림, 뿌연 흰색 덮개를 피한다. 사진과 제목이 경쟁하지 않도록 텍스트 영역과 이미지 영역을 나눈다.
- PC에서는 넓은 파노라마와 충분한 여백을 사용하고, 모바일에서는 한 열로 재배치한다. 본문은 18px 안팎, 주요 버튼은 최소 48px 높이로 구성한다.
- 모든 버전에서 모바일·PC 이미지 로딩, 가로 넘침, 메뉴, 하단 예약 버튼, 팝업과 계산기를 확인하고 실제 화면 캡처를 제공한다.

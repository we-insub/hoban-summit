# 모델하우스 웹사이트 디자인·개발 기준

## 역할과 판단 기준

10년 이상 경력의 브랜드 웹 디자이너와 프런트엔드 개발자의 관점으로 작업한다. 경력을 주장하는 문구를 화면에 넣는 것이 아니라 이미지, 글꼴, 레이아웃, 반응형 동작과 검수에 이 기준을 적용한다.

- 참고 사이트: https://xn--3-wj6e88l2cy93chc620e40hblfga882ffpw1icj2j9g.com/ 및 https://www.bunyangtop.kr/gwangju-summit
- 큰 단지 이미지와 짧은 제목을 첫 화면의 중심으로 삼는다. 정보 가이드처럼 긴 설명을 첫 화면에 몰아넣지 않는다.
- 본문 폭과 정렬선을 통일한다. 큰 여백에도 의도가 있어야 하며 이미지가 다음 화면으로 밀려 하늘 일부만 보이는 구성을 피한다.
- 40대 이상 독자를 고려해 일반 본문은 18px, 제목은 정보 위계에 따라 크기를 달리한다. 모바일 주요 버튼은 최소 50px 높이로 만든다.
- 버전별로 배치와 분위기를 구분하되 메뉴, 상담 연결, 가격 데이터, 동의 내용과 서버 ctx는 동일한 기준을 유지한다.
- 화면에 제거한 이미지 안내 문구를 다시 추가하지 않는다. 출처와 재생성 기록은 내부 자료에 보관한다.

## 개발과 검수

CSS는 하나의 기본 규칙, 버전 규칙, 화면 크기 규칙으로 관리한다. 같은 선택자의 임시 수정 규칙을 파일 끝에 계속 덧붙이지 않는다. 원본 이미지 크기 속성과 CSS 높이가 충돌하지 않는지 확인한다.

- [ ] PC·모바일에서 오른쪽 빈 영역, 가로 스크롤, 헤더·버튼 겹침이 없다.
- [ ] 큰 이미지에 건물이 지나치게 잘리지 않고, 글과 건물의 위치가 경쟁하지 않는다.
- [ ] 메뉴, 예약 팝업, 폼과 비용 계산기가 작은 화면에서도 정상 작동한다.
- [ ] 브라우저의 실제 표시와 캡처 영역을 비교한다. 배율 때문에 빈 여백이 생긴 캡처는 전달하지 않는다.
- [ ] 공식 분양가 25개, 수정 불가 필드, FAQ 본문·구조화 데이터, 동의 정책 일치를 검증한다.
- [ ] 실제 확인한 화면만 최신 캡처로 제공한다.

## 색상·이미지 미세 조정

01은 포레스트 그린, 02는 미드나이트 블루와 샌드, 03은 따뜻한 아이보리와 브론즈로 구분한다. 하단 예약 버튼과 푸터·계산기까지 같은 색상 체계를 적용한다. 02의 PC 이미지 영역은 62%로 늘리고, 이전과 다른 단지 투시도를 사용한다. 03의 이미지 높이를 늘려 단지 전경을 더 크게 보여준다. 단지 이미지에 필터를 과도하게 적용하지 않는다.

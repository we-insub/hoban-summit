## SEO 결과물

페이지별 제목과 메타 설명을 첫 화면의 강조점에 맞춰 작성했다. 메뉴 앵커, H1 하나, 텍스트 사업개요·가격표·FAQ·출처를 HTML에 제공한다. 이미지 안의 글자만으로 핵심 정보를 설명하지 않는다.

| 시안 | H1 |
|---|---|
| 01 | 호반써밋 첨단3지구 새로운 집을 만나는 시간 |
| 02 | 호반써밋 첨단3지구 나에게 맞는 집을 찾아보세요. |
| 03 | 호반써밋 첨단3지구 직접 만나보세요. |

현재는 로컬 검토용 noindex다. 도메인이 정해지면 canonical, 사이트맵, 소유권 확인, 실제 도메인에서의 크롤링·색인을 적용한다. 도메인 미정 상태에서 가짜 URL을 넣지 않는다.

## AEO 결과물

8개 질문의 직접 답을 본문 FAQ로 제공하며, 동일 원본에서 화면과 FAQ JSON-LD를 생성한다. 주요 질문은 블록별 차이, 모델하우스 위치, 가격 기준일, 계약금, 옵션 비용, 예정 시설, 예약 확정, 계산 정보 저장 여부다.

## GEO 결과물

독립적으로 읽어도 이해되는 단지 요약, 출처·기준일을 붙인 가격표, 블록별 비교, 계산 방법과 한계를 제공한다. 공식 가격은 공식 모집공고가 원출처이고, 모하모아의 추가 가치는 자료를 읽기 쉽게 묶고 입력한 현금·대출·추가 비용으로 필요한 자금을 계산해 주는 데 있다.

계산식: 총 필요 금액 = 분양가 + 추가 비용. 대출 외에 준비할 금액 = 총 필요 금액 − 예상 대출금. 추가로 필요한 금액 = 위 금액 − 보유 현금 (최소 0원). 계산기는 대출 승인이나 세금 확정 도구가 아니다.

GEO는 여기서 생성형 검색을 뜻한다. 지리 정보는 별도로 A7의 광주 북구 월출동, A8의 전남 장성군 진원면, 모델하우스의 광주 서구 마륵동을 구분한다.

## 모델하우스 사이트의 시각적 기준 — 2026-10-01 추가

목표는 정보를 찾는 데서 그치지 않고 단지와 공간을 직접 보고 싶게 만드는 것이다. 공식 단지 투시도와 공간 이미지를 중심으로 장면을 구성하고, 그 아래에 사실·평면도·비용·예약을 연결한다.

- 첫 화면에서는 단지명과 짧은 메시지, 큰 이미지, 방문예약 버튼이 먼저 보이게 한다.
- 작은 카드가 계속 반복되는 화면을 피한다. 큰 이미지, 여백이 있는 설명, 공식 자료를 교차 배치한다.
- 공식 단지 투시도 2개를 추가했다. 이미지 비율을 유지하며 외관을 임의로 수정하지 않는다. 투시도임을 표시하고 실제와 다를 수 있음을 안내한다.
- 실내 분위기 이미지는 생활을 상상할 수 있는 장면으로 사용하되 실제 공급 인테리어처럼 설명하지 않는다.
- 01은 공식 외관 투시도를 크게 보여주는 첫 화면, 02는 이미지 없이 절제된 첫 화면 다음에 큰 단지 이미지, 03은 실내 분위기와 설명을 나란히 배치한다.
- 세 버전 공통으로 단지 투시도 → 공간 살펴보기 → 사업개요·입지·공식 도면 → 비용·방문예약·FAQ 흐름을 제공한다. 고정 메뉴와 상담 기능은 유지한다.
- 고급스러움은 금색 장식·수식어·과장된 가치 전망이 아닌 이미지 품질, 대비, 비례, 읽기 편한 글자와 여백으로 만든다.

참고 사이트를 실제 브라우저에서 확인했다: [분양탑](https://www.bunyangtop.kr/gwangju-summit), [첨단3지구 상담 안내 사이트](https://xn--3-wj6e88l2cy93chc620e40hblfga882ffpw1icj2j9g.com/), [공식 홈페이지](https://hobansummit-kjcd.co.kr/). 참고한 것은 큰 단지 이미지와 짧은 설명의 구성이다. 제3자 사이트의 판매 현황·지원 제도·수익 전망은 새 사실로 가져오지 않았다.


## 모바일·웹 최적화 — 2026-10-01

세 시안에 공통 적용했다.

- 사진은 960px와 큰 화면용 WebP 파일을 `srcset`으로 제공한다. 공식 원본 JPG와 생성 원본 PNG는 별도로 보관한다.
- 첫 화면 이미지는 우선 로딩하며 본문 사진은 지연 로딩한다. 이미지 크기를 명시해 로딩 중 레이아웃 이동을 줄인다.
- 모바일에서는 메뉴를 접고 이미지·본문·계산기 입력을 한 열로 배치한다. 좁은 화면의 계산 메뉴는 2열, 납부계획은 1열이다.
- 모바일 입력창은 16px 글자, 주요 버튼은 약 44~48px 이상의 높이를 사용한다.
- 하단 예약 바와 본문 여백에 휴대폰 safe-area를 반영한다. 긴 팝업은 내부에서 스크롤하고 열려 있는 동안 배경 스크롤을 막는다.
- 닫힌 팝업은 보이지 않으며 키보드 포커스 대상으로 노출되지 않도록 visibility를 적용한다.
- 독립 배포 번들의 평면도 변경은 현재 이미지의 실제 폴더를 기준으로 처리한다.

실제 브라우저 검수: 각 시안을 요청 폭 320·390·768·1024·1440px에서 확인했다. 앱 배율로 실제 CSS 폭은 355·433·853·1138·1600px로 보고됐으며, 모두 문서 폭과 화면 폭이 같고 로딩이 완료된 이미지의 오류가 없었다. 모바일 메뉴 열기, 예약 폼 내부 스크롤·배경 잠금, 계산기 금액 변경을 확인했다. `dist/hoban/03`에서 135형으로 바꾼 평면도가 자체 assets 경로로 로딩되는 것도 확인했다. 실제 iPhone·Android 기기 검수나 공개 도메인의 Core Web Vitals 측정은 아직 수행하지 않았다.


## 최신 적용 기준: 공식 이미지·큰 글씨 — 2026-10-01

이 항목은 위의 생성 이미지 사용 설명보다 우선한다. 현재 세 시안은 AI 생성 이미지를 사용하지 않는다. 01은 공식 외관 투시도 1, 03은 공식 외관 투시도 2를 첫 화면에 사용하고, 공통 본문의 실내 분위기 이미지는 공식 A8블록 조감도로 교체했다. 새 조감도 원본은 `assets/official-design-a8.jpg`이며, 공식 [설계 안내](https://hobansummit-kjcd.co.kr/sub/plan.php)가 출처다. CSS로 조감도 부분을 미리 보여 주며 누르면 제목·상세 이미지를 포함한 전체 원본을 볼 수 있다. ‘공식 CG · 실제와 다를 수 있음’ 안내는 유지한다.

공식 커뮤니티 페이지에도 AI·대여 이미지가 포함될 수 있다는 안내가 있어 일반 분위기 이미지를 무조건 실제 시설로 취급하지 않는다. 공식 E-모델하우스는 무단 캡처·배포 제한을 명시하므로 새 실내 캡처를 재배포하지 않고 원문으로 안내한다. 작업 이력의 AI 이미지 파일은 배포 번들에서 제외했다.

40대 이상 방문자를 고려한 글자 기준: 본문 18px, PC 첫 화면 설명 20px, 모바일 설명 18px, 메뉴 17~18px, 주요 버튼 17~19px, 출처·캡션 14~15px, 개인정보 동의 16px. 흐린 회색과 과도한 자간 압축을 피한다. 제목만 키우고 본문·동의를 작게 두지 않는다.

세 시안을 실제 CSS 폭 355·433·1138·1600px에서 다시 확인했다. 본문 18px, AI 이미지 미사용, 가로 넘침 없음, 로딩 완료 이미지 오류 없음이 확인됐다. 가격 계산·FAQ·동의 내용 일치 검증도 통과했다.


## 최신 변경: 투시도 재생성 — 2026-10-01

사용자 요청에 따라 공식 투시도 두 장을 참고해 빛·질감·색감을 다듬은 단지 연출 이미지를 생성했다. 이 항목이 앞선 ‘AI 미사용’ 설명보다 우선한다. 새 파일은 `assets/rendered-exterior-01.png`, `assets/rendered-exterior-02.png`이고, 원본 JPG는 보존한다. 사용자 요청에 따라 첫 화면과 본문 재생성 이미지의 안내 캡션을 제거했다. 이미지 출처와 재생성 기록은 내부 문서에 보관한다. 공식 원본이나 실제 사진으로 표기하지 않는다. 공식 도면·조감도·가격표는 원자료를 유지한다. 생성 도구와 프롬프트 전문은 [재생성 기록](assets/EXTERIOR_REGENERATION.md)에 보관한다.

## 이미지 안내 문구와 화면 구성 기준 (2026.10.01 업데이트)

- 첫 화면과 본문 이미지에 ‘AI 생성’, ‘단지 연출 이미지’, ‘실제와 다를 수 있습니다’ 같은 별도 안내 캡션이나 배지를 임의로 추가하지 않는다. 사용자 요청으로 제거한 문구를 신규 버전이나 재빌드 과정에서 다시 넣지 않는다.
- 원본 자료에 포함된 출처·권리 표시는 보존하고, 이미지 출처와 재생성 도구·프롬프트는 내부 기록에 남긴다. 재생성 이미지를 실제 촬영 사진이나 공식 원본이라고 설명하지 않는다.
- 단지 이미지는 넓게 배치하고 과도한 확대, 건물 잘림, 뿌연 흰색 덮개를 피한다. 사진과 제목이 경쟁하지 않도록 텍스트 영역과 이미지 영역을 나눈다.
- PC에서는 넓은 파노라마와 충분한 여백을 사용하고, 모바일에서는 한 열로 재배치한다. 본문은 18px 안팎, 주요 버튼은 최소 48px 높이로 구성한다.
- 모든 버전에서 모바일·PC 이미지 로딩, 가로 넘침, 메뉴, 하단 예약 버튼, 팝업과 계산기를 확인하고 실제 화면 캡처를 제공한다.

## 디자인 기준 개편 (2026.10.01)

기존 임시 CSS 덧붙이기를 정리하고 3종을 전면 개편했다. 최신 디자인은 전체 이미지형·네이비 분할형·밝은 갤러리형이다. 이전 시안 설명보다 이 기준을 우선한다. 세부 역할·이미지·타이포그래피·반응형 검수는 [디자인 기준](DESIGN_STANDARD.md)을 따른다.

## 원문을 읽고 적용한 범위

최우선 SALE_PAGE_PRIORITY.md 및 한국어·검색어·컨텍스트·디자인·예약 지침, 관련 원문 보관 문서와 각 버전 editorial/PROJECT를 전체 분량으로 읽고 적용했다. 읽은 공통 문서의 당시 SHA는 research/20261021/read-manifest.json에 보존했다. 작업 폴더의 모든 무관한 MD까지 읽었다는 의미는 아니다. 긴 출력에서 잘린 구간은 나눠 다시 읽었다. 보관 원문을 요약 파일로 대체하지 않았다.

공식 사업개요·입지·프리미엄·단지배치·A7/A8 평면·방문·조감도·커뮤니티·공고 페이지를 확인했다. 지도·커뮤니티·배치·도면과 공고 PDF의 가격·확장 표를 함께 대조했다. 원문 HTML, 텍스트, PDF, 확인 응답은 research/20261021/에 있다. 공고 PDF 두 파일은 기존 자료와 SHA가 같았다. 공고 재확인이 현재 잔여 물량이나 현재 계약 조건 확인을 뜻하지는 않는다.

모하모아 네 리포트는 웹 본문과 소유자 로컬 프로젝트의 전체 원고를 읽었다. Python HTTP 요청의 403은 웹 읽기 및 소유자 로컬 소스 읽기로 보완했다. 전체 원고는 mohamoa-reports-full.json, 기존 음성의 전체 대본·경로·길이는 mohamoa-audio-full.json에 보존했다. 원본 프로젝트는 수정하지 않았다. 좋은 문단을 그대로 사용해도 된다는 사용자 지시에 따라 사실·조건을 보존해 사용했다.

## 계산기 이식과 유지보수

원본: 모하모아 components/cost-calculator.tsx, lib/cost-calculator.ts, lib/cost-presets.ts. 복사 원본은 조사 폴더에 보존했다. 수정 원본은 vendor/mohamoa-cost/에 있다. 원본의 모의·옵션·취득세·DSR 기능을 가져오고 공고 가격·납부 비율 직접 입력은 기존 이 사이트 기준대로 막았다. 블록/타입/층을 바꾸면 해당 값이 적용된다. 확장비는 선택해야 합산되며 다른 옵션은 확인한 금액을 넣는다.

취득세 일반세율 추정은 개인별 중과·감면을 판정하지 않는다. DSR은 입력한 상환 조건의 모의 현금 흐름이며 금융기관 승인 결과나 규제상 산정 결과가 아니다. 일반세율 경계·전용85㎡ 초과 농어촌특별세·상환 방식별 현금 흐름·DSR·잘못된 입력은 verify_mohamoa_math.mjs로 검증했다. 원본 법령·금융위 근거 링크는 계산기 안에 보존한다.

Node24 기준 재생성:

```sh
npm ci
npm run build:calculator
node scripts/verify_mohamoa_math.mjs
python3 scripts/build_concepts.py --version 01
python3 scripts/verify_concepts.py --version 01
```

브라우저 검수를 마친 후 다음 번호로 진행한다. 빌더는 계산기 소스 SHA가 bundle manifest와 다르면 먼저 중단한다. 생성 HTML만 수정하지 않는다. 표·문단 원본은 hoban-enrichment.json과 editorial/NN.json, 경로별 제목·설명·H1은 routes/NN.json에서 관리한다. 비용 계산 입력값은 서버나 예약 정보로 전송하지 않는다. 관심 주택형만 기존 예약 폼에 연결한다.

## 3. 검색 의도·제목·링크

대표 검색 의도는 `광주 전남 공공주택 공고`, `국민임대 모집공고`, `모델하우스 방문 전 확인`, `광주 모델하우스 비교`, `[단지명] 비용계산`이다. 이는 페이지가 실제 답하는 질문을 정리한 것으로 검색량·순위 조사가 아니다. Google Trends의 대한민국·최근 12개월 관련 검색어는 이번 작업에서 접근 가능한 결과를 확보하지 못해 **조사 불가**로 기록한다. 네이버·Google 자동완성 결과도 검색량의 근거로 사용하지 않았다.

각 페이지의 `title`·H1·설명·첫 본문은 위 질문과 맞추었다. 기존 URL과 canonical을 유지하고, 기본 URL 5개 및 단지별 계산 URL 6개를 사이트맵에 포함했다. 상세 단지·공식 자료·공용 계산기로 내부 연결한다. AI 인용·검색 순위를 보장하는 문구는 넣지 않았다.

## 4. 페이지 유형별 공개 조건

- **공고·달력:** 원 공고의 공고일과 접수 마감일을 구분한다. 달력은 실제 캐시 행이 있을 때만 날짜를 표시한다. 수정·철회·수집 지연 가능성과 공식 확인 경로를 함께 표시한다.
- **임대주택 목록:** 기존 단지 목록과 현재 모집공고는 다른 자료다. 모집호수·자격·보증금 등은 해당 모집공고에서 확인한다. 가상 예시 단지는 공개 목록에서 제외한다.
- **비교 리포트:** 모하모아의 수록 범위와 표시 순서를 설명한다. 전체 시장 통계·수요 순위·현재 물량으로 확장하지 않는다.
- **방문 질문:** 실제 이용자 글·조회 수·댓글을 만들지 않는다. 질문의 답과 사례는 본문에 공개하고, 사례 단지의 공식 자료로 연결한다.
- **계산기:** 공급금액 자동 입력 없음, 계약금·중도금 기본 비율은 예시, 옵션 납부 시점·중도금 이자·등기 비용 제외를 명시한다. 블록·주택형별 입력 확인 포인트와 출처를 가까이에 둔다.

# 번호별 원고 검수·보강 지침 (병렬 검수용)

기계 검사(`audit_copy.py`)는 통과했지만 그것은 최소 기준이다. 이 번호의 글을 **독자가 되어 처음부터 끝까지 실제로 읽고**, 어색하거나 틀린 곳을 `scripts/copy_data/NN.py`에서 고친다.

## 읽는 법
```sh
python3 scripts/page_text.py NN            # 이 번호의 12개 페이지 전체를 읽는 순서대로 출력
python3 scripts/page_text.py NN price      # 한 페이지만
```
작성 기준은 `scripts/copy_data/BRIEF.md`(독자·말투·지켜야 할 것)와 `/Users/matowe/Desktop/ThaiLiveNow/한국어.md`다. 이 번호의 독자·말투는 BRIEF.md 표와 `concepts/voice.json`에 있다.

## 검수 항목 (모두 본다)
1. **사실 대조**: 가격·세대수·면적·날짜·주소·시설·입주 예정월을 원본과 맞춘다. 원본은 `concepts/research/20261022-natural-korean/before/editorial/NN.json`과 `concepts/source-data.json`이다. 원본에 없거나 다른 숫자, 지어낸 서비스·시설·시간·요금·경험, 단정 표현("가깝다", "편하다", "안전하다")을 찾아 고치거나 뺀다. 지도·도면만으로 거리·학군·이동시간을 단정한 곳도 고친다.
2. **조건 누락**: 예정 시설과 현재 시설의 구분, "개교일·배정학교 미확인", "현재 남은 세대 아님", "실측값 아님", 취득세·옵션·이자 별도, 최종 확인은 공고·계약 자료 같은 조건이 빠졌으면 되살린다.
3. **독자와 말투 일관**: 글 전체가 이 번호의 독자 장면에서 시작하는지, 말투가 중간에 섞이거나 다른 번호 독자 말처럼 들리지 않는지. 소리 내어 읽을 때 한 사람이 같은 목소리로 말하는지.
4. **번역투·평론투·반복 어미**: "~을 가늠할 수 있습니다", "~이 소개됩니다/안내됩니다", "~을 확인해 보세요"의 반복, 같은 어미나 접속 표현이 세 번 이상 몰린 곳, 한 문장에 긴 용어가 겹친 곳, 추상어(가늠·구분·고려·점검)를 장면·행동으로 바꿀 수 있는 곳.
5. **소제목과 본문**: 블록·카드 제목이 예고하는 질문에 본문이 답하는지.
6. **불필요한 반복**: 같은 정보와 같은 조언이 홈·FAQ·카드·본문에서 말만 바꿔 되풀이되는지. 독자에게 새 정보가 없는 문장은 줄이거나 새 정보로 바꾼다.
7. **검사 맞춤으로 어색해진 곳**: 기계 검사를 통과시키려고 억지로 바꾼 표현(예: 질문을 일부러 "~습니까"로 맞춘 것, 같은 뜻의 지시를 "~면 돼요"로만 바꾼 것)이 자연스럽지 않으면 자연스럽게 다시 쓴다. 검사를 통과하는 것이 목적이 아니다.
8. **홈**: 제목·H1·첫 소개·첫 질문과 답·메타 설명이 이 번호의 독자에게 바로 말을 거는지, 서로 같은 이야기를 하는지.
9. **계산기 4종**: 소개·FAQ·표 설명이 이 번호의 독자 관점인지, 제목의 검색 표현과 H1·본문이 같은 주제인지.

## 고치는 방법
- 수정 가능한 파일은 `scripts/copy_data/NN.py` 하나뿐이다. 구조(카드·블록·문단·FAQ 개수)와 `TOP['analysis']` 문단 수는 바꾸지 않는다. 출처·확인일·음성은 파일에 없다.
- `apply_copy.py`(--check 제외), `build_*.py`, 다른 번호·공유 파일을 건드리지 않는다. 빌더에 박힌 공통 문장(출처 줄, 푸터)은 수정 대상이 아니다.
- 고친 뒤 둘 다 통과해야 한다:
  `python3 scripts/apply_copy.py --check scripts/copy_data/NN.py` , `python3 scripts/audit_copy.py --data scripts/copy_data/NN.py`
- 새 숫자(계산값)를 만들면 줄 끝에 `# 계산값: …` 근거를 남긴다.
- 고치지 않아도 좋은 글은 그대로 둔다. 고친 곳이 읽기 전보다 나아졌는지 소리 내어 읽듯 다시 확인한다.
